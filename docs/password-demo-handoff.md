## 手機驗收

1. 開啟新站首頁，選茶、加入購物車並結帳，確認完成頁顯示短訂單編號。
2. 按「複製訂單編號」，確認只複製短編號。前往查單，沿用同一分頁資料與安全憑證。
3. 新站後台以私下提供的展示密碼登入，不要求填入憑證或簡訊驗證碼。
4. 確認新訂單出現在後台，人工確認付款、選取包裝照片、確認包裝，再手動出貨。
5. 回顧客查單確認狀態，再測已送達。其他站的舊訂單不應出現在新站。
6. 密碼錯誤須拒絕登入；連續錯誤應暫時鎖定。未登入直接呼叫後台業務 API 也應拒絕。

## 正式綁定與簡訊

此密碼流程僅適用獨立展示環境，不能作為正式營運身分驗證。陳老師本人首次確認與手機綁定、Twilio 真實簡訊設定及實際手機收件驗證，仍是正式登入的啟用條件。展示密碼不寫入 Git、文件、公開網址或測試截圖。

## 更新現有站的必要條件

先取得 orders.sqlite、identities.sqlite、outbox.sqlite、catalog.json、media 及 packing-photos 的一致私密備份，並驗證恢復後的 UUID、短編號、安全憑證授權、狀態與照片皆一致；或完成可驗證的外部持久資料儲存。未達成前，不更新上述現有站。
