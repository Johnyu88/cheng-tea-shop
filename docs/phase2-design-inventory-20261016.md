## 現況觀察與差異清單

### 1. 字體與文字層級

- body 使用 system UI；品牌、h1、h2、商品標題使用 Georgia／Noto Serif TC fallback，尚未形成完整字級、行高、字重 token。
- 首頁主標、人物介紹、商品卡、聯絡區在手機上形成很長的單欄閱讀流；資訊重要性主要靠大小與間距區分，缺少明確的 section rhythm。
- 導覽按鈕與內容標題都使用較重字重；需要重新定義「品牌標題／頁面標題／區段標題／輔助說明／價格」的階層與可讀寬度。

### 2. 色彩與品牌一致性

- 目前核心色為 paper `#faf8f2`、ink `#20352e`、mist `#dbe6dc`、tea brown `#8b6446`，方向已具茶席與紙本感。
- 深茶綠同時承擔導覽、主要 CTA、篩選、聯絡按鈕；茶褐色同時承擔輔助文字、焦點與放棄操作，後續應建立 primary／secondary／quiet／danger 的語意 token。
- 大量膠囊按鈕與圓角卡片讓頁面語氣一致，但也降低了主要行動與一般連結的差異。

### 3. 按鈕與商品卡片

- PHASE1 已處理購物車／結帳主要操作並列與 48px 觸控高度；其餘商品頁與目錄仍可統一按鈕高度、內距、focus 狀態與主要／次要層級。
- 商品卡片目前是圖片、口感標籤、名稱、摘要、規格價格、查看茶品的直向結構；圖片比例、摘要高度與價格辨識度仍可形成更一致的卡片節奏。
- 商品圖片使用自然比例 contain，符合不裁切素材的約束；後續只能調整容器、留白與資訊配置，不覆寫原檔。

### 4. 首頁視覺構圖

- 現況順序為 hero → 人物／茶席合成照與鳥鳴 → 推薦三款 → 完整商品瀏覽 → 聯絡陳老師；手機截圖可見內容完整，但頁面較長、轉換節點較分散。
- 人物故事與茶湯／茶席素材目前以一個 media grid 呈現；需評估在不裁切素材的前提下，如何讓「人物信任 → 茶席感受 → 選茶行動」成為更清楚的視線路徑。
- 桌面與手機使用同一套語意結構，但目前主要差異由 CSS breakpoint 處理，尚未形成桌面構圖與手機閱讀的明確 art direction。

### 5. 人物、茶湯、茶葉照片完整呈現

- 已有素材：`teacher-hero-desktop-candidate.png`、`teacher-hero-mobile-candidate.png`、`teacher-portrait.webp`、`teacher-story.mp4`、`tea-stream-birds.wav`。
- 商品素材：8 張茶品照片與 `tea-sample-composite.png`；另有 `chen-teacher-line-qr.svg`。
- 現況未見素材原檔裁切或替換需求；PHASE2 應先做版位、比例、alt、載入與角色盤點，再決定是否需要新增素材。

### 6. RWD

- PHASE1 已驗證 390、412、768、1080、1440px 無水平捲動。
- 目前 40rem breakpoint 同時處理導覽、hero media、商品 grid、cart article、form actions；後續需檢查 768px 附近的折行與桌面／平板過渡，而非只看 390px。
- Header 在窄螢幕上品牌與三個膠囊入口佔用比例高；PHASE2 可評估固定導覽密度、文字換行與觸控區域的平衡，但不得回退 PHASE1 的可操作性。

### 7. 素材庫缺口

- 尚未有明確品牌字體檔、完整色票／印刷規範、茶席細節圖、每款茶的統一比例主圖、包裝／沖泡／產地補充圖與可供桌面 hero 使用的獨立構圖素材。
- 目前不能把候選合成照、商品照片或音訊視為已獲准重新裁切、調色、替換或生成新品牌素材。
- 若後續需要補素材，應先取得來源、授權、尺寸／比例、alt 文案與使用位置，再另行核准素材施工。

## PHASE2 建議順序（只作為待核准方案）

1. 建立 typography、spacing、color semantic tokens，先只整理 CSS 與元件語意，不變更素材。
2. 以首頁、商品卡、購物車、結帳四條前台路徑建立按鈕與卡片層級規範。
3. 重新檢視首頁 hero／人物／茶席／商品導覽的段落節奏，保留現有素材完整呈現。
4. 以 390／412／768／1080／1440px 做同一組 RWD review，特別檢查 768px 過渡與桌面留白。
5. 只有在素材缺口確認並獲核准後，才提出素材補拍、補圖或品牌美術變更。
