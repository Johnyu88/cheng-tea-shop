## 主持流程觀察

### 已修正的 dry-run 工具問題

- Next dev server 在此隔離工作樹的 `node_modules` junction 下，Turbopack 會拒絕工作樹外 symlink；改用 `--webpack` 仍因開發資源／host loading 限制無法穩定提供目錄互動。最後使用已驗證的 standalone server，仍是 localhost，沒有部署或付費服務。

- T5 的第一版檢查把商品名稱錯誤限制在「購物車摘要」region；實際商品列位於購物車內容區。已改為檢查商品列與數量 `2`，未修改產品程式。

### 可供真人走查前確認的流程摩擦

- T3 從購物車進入 checkout 後需填聯絡資料、按下一步、填配送地址、再按下一步；這是目前三步 checkout 的預期路徑，主持人應一次只念一個動作。
