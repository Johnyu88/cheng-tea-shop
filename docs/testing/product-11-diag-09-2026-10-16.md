## What can be done without changing the formal site

An operator can use an already available desktop browser's Network panel or approved remote-debugging view to observe a controlled browser operation through the same `:10001` URL. Capture only:

- request method and path;
- HTTP status and elapsed time;
- response headers `x-demo-request-id`, `x-demo-instance-id`, `x-demo-write-status`, and `x-demo-sync-status` if present;
- response body fields `ok`, `error`, and `value.id` only, with cookies and personal/product content redacted.

The operator must not retry POST when the response or follow-up GET is unknown. A missing response is an uncertain outcome, not proof of failed persistence.

Direct Samsung Z Fold6 browser tooling is not confirmed available in this environment. Therefore a desktop Network capture would diagnose a controlled browser session, but cannot be claimed to reproduce the phone's exact transport path unless the same phone session is remotely inspected.
