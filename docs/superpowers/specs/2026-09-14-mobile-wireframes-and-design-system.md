# Phase 1 手機 Wireframe 與小型設計系統規格

- 日期：2026-09-14
- 狀態：已確認並可寫入正式文件
- 階段定位：Phase 1 部分里程碑
- 實作狀態：尚未開始網站程式開發

## 1. 目標

把 Phase 0 已確認的品牌與購物體驗，轉成可供後續高擬真設計與實作使用的手機優先 Wireframe 和小型設計系統。

本里程碑優先服務：

- 使用手機選茶與購買的顧客。
- 不熟悉複雜網站操作的年長使用者。
- 需要自然、可信任、不催促之購物氛圍的茶行品牌。

## 2. 設計原則

- 手機優先，再延伸至桌機與其他響應式尺寸。
- 購買資訊先於長篇故事。
- 大字、清楚標籤、充足留白與容易點擊的操作。
- 保留自然、人情與信任感，不使用壓迫式促銷。
- 動態效果低調且可停用。
- 頁面資訊密度適中，一次只要求使用者完成一個主要任務。

## 3. 手機首頁 Wireframe

資訊順序已確認：

1. 茶山雲霧主視覺、簡短品牌話與「開始選茶」主要按鈕。
2. 清香、甘甜、濃郁、焙火四張口感選茶卡。
3. 三款精選茶品。
4. 陳老師與茶行的簡短故事。
5. 電話或 LINE「來店喝茶」次要入口。
6. 付款、配送與安心購買說明。
7. 地址、營業資訊、地圖與聯絡方式。

首頁未來可評估細微的山林微風或霧氣動態，但不得妨礙閱讀、操作與載入。

## 4. 手機商品詳情 Wireframe

首屏先提供完成購買所需資訊：

1. 商品照片。
2. 茶名與一句口感。
3. 價格。
4. 有貨／售完狀態。
5. 加入購物車主要按鈕。

後續再依序提供：

- 茶品故事。
- 產地與製程事實。
- 沖泡方式。
- 配送、付款及庫存不足處理說明。

售完商品仍可閱讀，但不得加入購物車。若下單後發現數量不足，茶行在 24 小時內電話聯絡，提供換貨或退款。

## 5. 手機購物車與三步驟結帳

已確認四個主要畫面：

1. 購物車。
2. 聯絡資料。
3. 配送方式。
4. 付款與確認。

結帳規則：

- 不強迫註冊。
- 手機號碼必填，Email 選填。
- 配送提供宅配與到店取貨。
- 宅配可用信用卡或 LINE Pay。
- 到店取貨可線上付款或到店付款。
- 運費與免運門檻由後台設定，不寫死在畫面元件。
- 每一步顯示目前進度，並保留返回修改能力。
- 驗證失敗或網路錯誤時保留已輸入資料。

## 6. 小型設計系統

### 6.1 色彩 Token

| Token | 色碼 | 用途 |
|---|---|---|
| Ink | `#26372F` | 主要文字、深色按鈕 |
| Leaf | `#587361` | 品牌綠、次要重點 |
| Mist | `#DFE9DF` | 淡霧綠背景 |
| Ivory | `#F7F3E9` | 網站主背景 |
| Paper | `#FFFDF7` | 卡片與表單背景 |
| Brown | `#775841` | 茶褐色重點 |
| Muted | `#66746C` | 次要文字 |
| Error | `#9B3B2D` | 錯誤與警示 |

已驗證文字對背景的 WCAG 對比值：

| 組合 | 對比值 |
|---|---:|
| Ink / Paper | 12.36 |
| Leaf / Paper | 5.11 |
| Brown / Paper | 6.34 |
| Muted / Paper | 4.82 |
| Error / Paper | 6.75 |
| Ink / Mist | 10.10 |

### 6.2 字體層級

| 層級 | 尺寸／行高 | 建議字體 |
|---|---|---|
| Display | 32px / 1.3 | 明體／襯線字 |
| Section | 25px / 1.4 | 明體／襯線字 |
| Body | 18px / 1.7 | 黑體／無襯線字 |
| Helper | 15px / 1.55 | 黑體／無襯線字 |
| 可編輯表單 | 至少 16px | 黑體／無襯線字 |

### 6.3 控制元件

- 觸控目標至少 48 × 48px。
- 輸入欄位高度至少 52px。
- 表單使用持續可見的文字標籤，不只依賴 placeholder。
- 鍵盤焦點必須清楚可見。
- 按鈕、連結、欄位與狀態使用語意化控制元件。
- 主要與次要操作在視覺上明確區分。

## 7. 必要互動狀態

後續高擬真設計與實作必須涵蓋：

- 載入中：使用穩定版面骨架，避免畫面跳動。
- 空狀態：清楚說明並提供下一個動作。
- 錯誤：以白話指出問題，保留已填資料並可重試。
- 售完：保留商品內容，停用購買操作。
- 付款處理中：防止重複送出。
- 付款失敗：保留訂單與聯絡資料，提供重試或改用其他方式。
- 成功：顯示訂單摘要、後續通知與可聯絡方式。

## 8. 山林動態與環境聲音

首頁高擬真階段可評估低干擾的霧氣／微風效果：

- 不影響文字清晰度與主要操作。
- 使用者偏好減少動態時，自動停止視覺動態。
- 不得成為頁面載入或購物流程的阻塞條件。

鳥叫與蟲鳴可作為選配的環境聲音：

- 預設關閉，禁止自動播放。
- 只有使用者明確點擊後才播放。
- 音量低，並隨時提供清楚的停止控制。
- 離開首頁時停止。
- 不干擾螢幕閱讀器、鍵盤操作或其他輔助科技。
- 聲音載入失敗不得影響網站其他功能。
